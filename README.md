# ✦ NOVA — Experience Sound

NOVA is a modern, interactive e-commerce experience designed around premium technology products.

The project combines a futuristic dark interface with interactive product browsing, shopping cart functionality, wishlist management, product filtering, responsive layouts, and an interactive 3D-style product showcase.

## 🚀 Live Demo

[View Live Demo](https://nova-ecommerce-eta.vercel.app/))

## ✨ Features

- 🛍️ Interactive product catalog
- 🔎 Product search
- 🏷️ Category filtering
- 🔥 Deals section
- ❤️ Wishlist functionality
- 🛒 Shopping cart
- ➕➖ Cart quantity controls
- 💰 Dynamic cart total
- 🎨 Product color selection
- ⭐ Product ratings
- 📦 Product availability indicators
- 🖼️ Interactive product image views

## 🎨 Design

NOVA was designed with a futuristic technology aesthetic.

The interface uses:

- Dark navy backgrounds
- Purple and blue gradients
- Glassmorphism-inspired navigation
- Soft neon glows
- Rounded cards
- Minimal typography
- Interactive product elements

The goal was to create an e-commerce interface that feels more like a premium digital product experience than a traditional online store.
